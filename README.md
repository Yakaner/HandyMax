# HandyMax

HandyMax 홈페이지 리디자인 (React + Vite).

## 실행

```bash
npm install
npm run dev      # 개발 서버
npm run build    # 프로덕션 빌드 (dist/)
```

## 구조

- `src/siteData.js` — 메뉴, 카드 문구, 이미지 매핑 (콘텐츠 수정은 여기서)
- `src/components/` — Header, Hero, Explore(아코디언 카드), CtaBanner, Footer
- `src/assets/images/` — 원본 이미지
- `docs/design-reference-main.webp` — 메인페이지 디자인 시안
